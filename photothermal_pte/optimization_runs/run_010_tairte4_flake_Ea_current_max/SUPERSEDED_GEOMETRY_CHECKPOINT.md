# Superseded geometry checkpoint

Run010 was intentionally stopped after accepted update 9.  It remains a valid
numerical checkpoint for the former 16 x 16 um design enclosed by a fixed
four-sided TaIrTe4 frame, but that geometry is no longer the selected physical
comparison contract.  No failure is inferred from stopping it.

The replacement Run012/Run013 contract fixes TaIrTe4 only at the top and bottom
contact strips and removes the left/right fixed frame.
